Delta is a script executor: an app that runs custom Lua scripts inside Roblox games. Players mainly use it for UI tweaks, automation in idle and farming games such as Grow a Garden, and testing scripts they've written themselves. What makes it popular: - **Free to use.** Access works through a short key system instead of a paid licence. - **Cross-platform.** It runs on phones, tablets and desktops. - **Fast setup.** On most devices it's running in about two minutes. - **Built-in script hub.** You can browse and run community scripts without copying them in by hand. Each new release follows the latest Roblox update, so check the build number before you install. --- ## 📱 Supported platforms | Platform | Install type | Notes | |---|---|---| | Android | APK | Allow installs from unknown apps in your settings | | VNG | APK (VNG client) | For the Vietnamese Roblox build | | iOS | IPA / sideload | iPhone and iPad | | Direct Install | One-tap link | The quickest route on supported devices | | Windows | Desktop app | Windows 10 and 11 | | macOS | Desktop app | Intel and Apple Silicon | --- ## 🤖 Android setup 1. **Download the APK.** Get the November 2026 build from the [Delta APK download page](https://dlta-executor.com/). 2. **Allow unknown apps.** Go to *Settings → Apps → Special access → Install unknown apps*, then turn it on for your browser. 3. **Install and open Delta.** Tap the downloaded file and follow the prompts. 4. **Get your key.** Delta asks for a key on first launch. See [Getting your Delta key](#-getting-your-delta-key). > 💡 If Play Protect shows a warning, that's normal for any APK installed from outside the Play Store. Only download from a source you trust. --- ## 🍎 iOS setup iPhones and iPads don't allow normal APK-style installs, so Delta is added by sideloading an IPA. 1. Download the Delta IPA file. 2. Install it with a sideloading tool, or use the Direct Install option if it's available for your iOS version. 3. Go to *Settings → General → VPN & Device Management* and trust the developer profile. 4. Open Delta, then open Roblox and attach it. Sideloaded apps on iOS can stop opening when their certificate expires. If that happens, reinstall the IPA. --- ## 💻 Windows & Mac setup 1. Download the desktop build for your system. 2. If your antivirus flags the file, add an exception before you extract it. Executors trigger false positives because they inject into another process. 3. Run Delta, open Roblox, then click **Attach**. 4. Paste a script or pick one from the hub, then press **Execute**. --- ## 🔑 Getting your Delta key Delta uses a free key system to keep the executor free: 1. Tap **Get Key** inside the app. This copies a link. 2. Open the link in your browser and complete the short checkpoint steps. 3. Copy the key that's generated, paste it back into Delta, and tap **Verify**. Keys expire after a set period, so you'll repeat this now and then. The **[Delta key guide](https://dlta-executor.com/)** explains how long a key lasts and what to do when one stops working. --- ## 🛠 Troubleshooting | Problem | Likely fix | |---|---| | "App not installed" on Android | Uninstall the old version first, then install the new APK | | Delta closes as soon as it opens | Roblox updated.
